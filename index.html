A Bun starter with nothing to install.

Write HTML, save data from it, and let Bun handle the rest. No build step, no database server, no backend code until you want some.

bunx degit anas1412/loaf my-app

Needs Bun 1.2.3 or newer. Then run bun dev. Read the docs

What you get

public/
Your pages. about.html is served at /about, no config.
loaf.js
Add collection('posts') to any element to list, save, update and delete posts.
api/
Custom logic when you need it. api/hello.js becomes /api/hello.
loaf.db
One SQLite file holds all your data. Don't need a database? Delete db.js.

Why it's this small

  • No setup

    No accounts, no database server, no .env to fill in before it runs.

  • No build step

    The HTML you write is the HTML the browser gets. View source shows your real code.

  • No dependencies

    Bun already ships the server, SQLite, file watching and the test runner.

  • No backend code

    Save and load data straight from HTML. Write routes only when you want custom logic.
