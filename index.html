Loaf GitHub

A Bun starter with nothing to install.

Bun serves your pages and keeps your data in SQLite. Alpine and Tailwind load from a CDN. Clone it, run bun dev, and start writing HTML.

bunx degit anas1412/loaf my-app

Needs Bun 1.2.3 or newer.

What you get

server.js
Your routes, plus serving everything in public/.
db.js
Opens loaf.db. That one file is your whole database.
public/
Plain HTML, images and scripts, served exactly as you wrote them.
demo/
A small notes app that shows the database, the API and the page working together. Delete the folder and the two gold lines to start clean.

Why it's this small

  • No setup

    No accounts, no database server, no .env to fill in before it runs.

  • No build step

    The HTML you write is the HTML the browser gets. View source shows your real code.

  • No dependencies

    Bun already ships the server, SQLite, file watching and the test runner.

  • Readable in five minutes

    A handful of short files. Add structure when your app needs it.
