Guide

Get started

On GitHub, with nothing to install

  • Open the Loaf repository and click Use this template → Create a new repository.
  • In your new repository, open Settings → Pages, pick the main branch and click Save.
  • A minute later your site is live at https://your-name.github.io/your-repo/.

Edit any file with the pencil icon on GitHub, and the site updates by itself.

On your computer

Download the repository (Code → Download ZIP), unzip it, and open the folder with any local web server, for example:

Or use the "Live Server" extension in VS Code. Double-clicking the files doesn't work, because browsers don't let pages load other files from your disk.

Add a page

Create about.html:

The first line goes at the top of every page. It adds the header, footer, styles and everything else, so the page only needs its own content. The <title> is the name in the browser tab.

Header and footer

Every page shares these files:

  • _header.html: your logo, links and the theme menu
  • _footer.html: the bottom of every page
  • _layout.html: the page frame around them

Add a link to your new page in _header.html and it shows up everywhere:

Links and images are relative to your site's main folder, so write about.html or photo.jpg, not /about.

Save things

Here's a whole notes app. Create notes.html:

  • <loaf-form name="notes"> saves what you type. The name can be anything: recipes, contacts, ideas.
  • <loaf-list name="notes"> shows everything saved, newest first.
  • field="text" shows the input named text.

Everything is saved in the visitor's own browser. It stays after refreshing and closing the browser, it never leaves their device, and each visitor only sees their own. That makes it right for personal tools like notes, to-do lists and trackers, but not for things visitors share, like a guestbook.

More things a list can do

Put these inside a <loaf-list>:

Add thisWhat it does
<p edit="text"></p>shows the text; click it to change it
<input toggle="done">a checkbox that remembers
<button remove>Delete</button>deletes the item
<p field="created_at"></p>when it was saved

And these anywhere on the page:

Add thisWhat it does
<loaf-count name="notes"></loaf-count>how many there are
<loaf-empty name="notes">No notes yet.</loaf-empty>shows only when there are none

Put it online

Any service that hosts plain files works: GitHub Pages (see Get started), Netlify (drag and drop the folder) or Cloudflare Pages.

Keep the empty .nojekyll file: without it, GitHub Pages skips the files starting with _.

Update Loaf

The first line of each page loads Loaf 0.2, which includes every 0.2 fix automatically. When a new version like 0.3 comes out, change @0.2 to @0.3 on your pages.

Remove what you don't need

  • The demo: delete demo.html and its link in _header.html.
  • The tests: delete the test/ folder.

For developers

Everything above works without this section.

  • loaf.js is the whole of Loaf: one file, no build step. It loads Tailwind, daisyUI and Alpine.js, then builds each page in the browser.
  • The loaf- elements are built on x-data="collection('notes')", which gives you items, add(), update(), remove(), loading, saving and error. Inside <loaf-list>, the current item is item, so Alpine attributes like :class="item.done && 'line-through'" work there too.
  • Data is stored in localStorage, one key per collection, separate for each site folder. Other open tabs of the same site update live.
  • data-layout="none" on the script tag skips the layout, and data-layout="_other.html" uses a different one.
  • Open test/ through a local server to run the browser tests.
  • .claude/skills/ teaches AI assistants how Loaf works. Update the daisyUI one with curl -sL https://daisyui.com/llms.txt -o .claude/skills/daisyui/SKILL.md.
